把写稿拆成五道工序。每一道只做一件事，改动的痕迹留在稿子里。

## 五阶段

### 1. 梳理

写不下去时先别写。至少问自己五个问题：核心问题、文章定位、结构、取舍、落点。只启发，不代写。

### 2. 成文

把散乱素材整理成带标记的初稿。初稿可以长、可以散；不确定的地方标【待填】【提问】【选择】，不编造。

### 3. 作者处理

回答【提问】、选定【选择】、填【待填】、加【！】、决定【删？】；用 `&` 行写清意图。

### 4. 执行

结算标记。只在明确指令下重排、扩写、加过渡；【待填】不代填。改写用【改】，删除用【删】。

### 5. 审稿

冷眼读八个维度：结构、聚焦、叙述与感悟、逻辑、节奏、结尾、整体、观点。至少给自己五个硬问题。

> 回答硬问题 → 执行 → 再审，循环到满意或发表。

## 标注符号

| 标记 | 用途 |
|---|---|
| 【待填：…】 | 需要作者补经历、细节 |
| 【提问：…】 | 需要作者澄清 |
| 【选择：A/B/C】 | 给出方向让作者挑 |
| 【润】 | 表达不到位，建议重写 |
| 【重写】 | 整段推翻 |
| 【删？理由：…】 | 建议删，但不主动删 |
| 【不改】…【/不改】 | 保护区，一字不动 |
| 【！想法】 | 作者的新想法，下一轮展开 |
| `&` 行 | 给执行者的指令，不进入正文 |
