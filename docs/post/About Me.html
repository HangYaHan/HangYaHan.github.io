想象一下，随着时间的推移，你的博客将成为一个充满个人智慧和经验的宝库，它不仅是你的成长记录，也是你与世界分享的桥梁。每篇博文都可能启迪他人，帮助他们看到不同的思考角度，甚至可能影响他们的生活决策。

记住，伟大的旅程总是始于足下的一小步。相信自己的能力，坚持自己的兴趣，让博客成为你表达自我、记录生活、与世界对话的窗口。你已经拥有了开始的勇气，接下来就是持之以恒地走下去，每一步都值得骄傲。加油，让世界见证你的成长与精彩！

Why Blog?

面对时间的无情流逝，人类总渴望留下些许痕迹：无论是思想的火花、珍贵的记忆，还是对生活的感悟与记录。每当看到那些内容丰富、充满智慧的博客时，我总会心生羡慕——或是知识的总结、生活的点滴，或是技术的分享、人生的思考，又或是对世界的深刻洞察。不止一次，我也萌生了拥有自己博客的念头，想要记录下自己的生活片段，分享所思所想，并将其珍藏。

曾经，我一直觉得拥有自己的网站是一件非常酷的事情，但总是因为拖延和懒散而迟迟未能付诸行动。如今，我终于下定决心，踏上这段创建个人博客的旅程。过去的我或许把这件事想得过于复杂，认为建立一个网站需要高超的技术能力。然而，当我真正开始行动时，才发现技术并非最大的障碍，反而是在内容上的空缺。内容才是博客的灵魂，是吸引读者的关键。我并没有深刻的思考，也没有独到的见解，甚至连自己的生活都过得平淡无奇。这样的我，真的有资格开设一个博客吗？我不知道。与其说是资格的问题，不如说是勇气。我想要去尝试，去记录，去分享。即便我的内容平凡无奇，但它们也是我生活的一部分，是我对世界的观察与思考。

Why GitHub?

与其他的平台（如 QQ、微信等）不同，GitHub 已经成为了当代计算机科学领域的重要基石。无数人、无数项目直接或间接地依赖于 GitHub，它已然成为了不可或缺的数字基础设施。GitHub 不仅仅是代码托管平台，更是全球开发者社区的汇聚地。它承载着无数开源项目、技术讨论与创新思想，成为了推动技术进步的重要力量。

下面这段话令我印象深刻，我认为它非常精确地命中了我想在 GitHub 上写Blog的感受：

人总想留下某种痕迹，证明自己活过，然而事实上，99.999% 的普通人就这么被历史遗忘了——曾经是这样。我们处在信息时代的早期，同样也处在人类文明的早期。从今往后，被数字化的东西只会越来越多。既然有人意识到了 GitHub 的独特性，随着时间推移，越来越多的人总会意识到。那时候会发生什么？自然是，越来越多的人会把自己的信息搬到 GitHub 上，依托 GitHub 实现曾经人们可望而不可及的"永生"。人有两次死亡，第一次是肉体，第二次是被人忘记。我忘记这句话是谁说的了，但现在我们已经可以回避第二次。只要 GitHub 支持，就一定会有人这么做，至少我是其中之一。几十几百年后，GitHub 将成为世界上最大的数字公墓，注册用户大部分都已去世，然而个人主页，项目，commit 历史 还述说着他们生前做过的事——就比如 Joe 的博客。这虽然是个比较 creepy 的推论，但从另一个角度想，却证明了人类的巨大进步：对抗死亡是人类文明的永恒主题，而我们已经实现了阶段性胜利。现在是文章、照片、视频，也许还有以个人习惯作为输入训练的模型。再往后呢？会不会有基因信息，乃至意识的完整复制呢？依托于稳定的存储，我们能做的事情实在太多了。反例是现在的一些 Memorial Websites，他们把逝者的信息放在自己网站上供亲友吊唁。这不能说没用，但在我看来去使用这类服务实在有些草率——就算他们再信誓旦旦，也摆脱不了某一天关站的风险，那时候还指望他们好好管理这些数据？没可能的。既然 GitHub 变成数字公墓是一种必然，我对他们的唯一希望，就是保持某种道德义务。我完全可以想象某一天他们出台一个政策，把二十年内没有活动迹象的账户全部 archive，GitHub Pages 全部下线。那就实在太恐怖了。我祈祷那一天不会到来。 --- From [laike9m]

Introduction

在这个博客中，我将主要分享我的思考、读书笔记、原创作品、个人感想以及一些日常的碎碎念。回想起来，我曾有几位初中同学自行创建了个人百度贴吧，并在其中分享他的见解与感悟，几个月前看他还在更新。如今看来，他从那时起便开始积累观点与想法，至今或许已积攒了一笔颇具价值的记忆财富。记忆财富就好比是陈年的美酒，越久弥香。随着时间的推移，曾经的记忆会愈发珍贵。这让我意识到，利用属于个人的“网上空间”来记录这些点滴，实在是一件极其有意义的事情。然而，时间无情，许多想法和记忆随着时间的推移逐渐淡化消逝。古人云：“已往之不谏，知来者之可追。”如今，我决定从现在开始记录，相信此举并不为晚。

有时，我也会想，当把自己的想法思考通过文字表达出来时，它们将会不再占用我的大脑的“内存”。一方面是这些想法本身不再占用，另一方面是担心忘记这些想法以及相关的纠结也不再占用。或者简单来说，这件用文字表达想法让我感到很爽。
