About Me

关注我的博客时间较早的朋友，大概会注意到早期的“About Me”页面里，几乎找不到一段像样的自我介绍。这不是因为懒，也不是因为忙，而是因为我一直在犹豫——甚至可以说是某种怯懦——面对“我该如何介绍自己”这个看似简单、却异常复杂的问题。

我并非大师，也不是名人，没有足以让他人一眼锚定我价值的显赫成就。因此，这篇短短的自我介绍，无形中承担了过重的责任：它要在有限的篇幅里，让一个陌生人快速理解“我是谁”。可一个根本性的难题始终横亘在那里：究竟什么样的文字，才能较好地“还原”一个活生生的人呢？如果缺乏真实材料的支撑，任何自我介绍都难免显得空洞，像一场没有实体的表演。

那么，我该选择怎样的演出形式？是罗列那些客观的、冷冰冰的物质条件与社会标签——学历、职业、收入——像一份被极度压缩的人生简历？还是倾注那些主观的、带着强烈自我滤镜的感受与评价——比如声称自己“乐观”、“热爱自由”？前者固然清晰，却仿佛只描摹了人的轮廓，无法触及血肉与灵魂；后者听起来真诚，却又极易流于空泛，甚至在不经意间，透出一丝自恋或自怜的气息。我长久地在这两极之间摇摆，深感表达的无力与局限。

更深层次的方面是，《道德经》里说：“大道废，有仁义；智慧出，有大伪；六亲不和，有孝慈；国家昏乱，有忠臣。”其中一种解读是，一个人往往越缺少什么，就越会刻意地强调什么。正因为内在的缺失，才需要向外寻求补偿，希望通过言语的炫耀或强调，来填补内心的空洞与不安。缺少学历的人看重学历，缺少金钱的人炫耀金钱，缺少爱的人反复诉说爱。我害怕自己也不自觉地坠入了这个逻辑的陷阱，在自我介绍中用力过猛地塑造某个形象，以此来掩盖内心深处的不足。这种恐惧，曾让我羞于启齿。

但后来，我慢慢想通了。承认自己的局限与不足，或许并没有那么可怕。愈是拼命掩饰，愈是暴露无遗。坦诚，反而是一种解脱。

我想

我是一个活得很“公式”的人。 我会在一家认可的餐馆反复用餐，会让老板和老板娘都记住我的口味；我会用最笨拙却踏实的方式工作，别人投机取巧的方法我学不来，只会一步一个脚印地“暗部就班”；我的思考也常遵循某种固定路径，别人没教过的东西，我往往需要更长时间才能领悟。与其说我热爱井井有条，不如说我安于现状，内心深处害怕变化，畏惧不确定性，不敢轻易冒险。

我是一个缺乏安全感的人。 在做很多事情时，我都显得蹑手蹑脚，生怕犯错，害怕被否定，恐惧失去已经拥有的一切——无论那有多么微小。这种心态渗透在工作、情感与人际交往的每一个角落。明明已到了被认为可以“随心所欲”的年纪，却依然有许多事情，因为胆怯而不敢尝试。

我是一个多愁善感，并努力学着知足与活在当下的人。 我很念旧，我的博客里记录了众多与此相关的思绪，这正是因为我长久以来都在与这些情绪和命题搏斗。另一方面，也因为我开始真正体验到文学带来的慰藉与力量，并尝试用尚且稚嫩的文字，将它们一一记录下来。

最后，我是一个喜欢创造的人。 尽管我做出来的东西可能破破烂烂，在别人眼里不值一提，但因为它是我亲手搭建、一点一滴完成的，所以对我而言，它就拥有了独一无二的意义。这个世界上，有人生来含着金钥匙，拥有常人难以企及的财富或权力；有人天生丽质，被爱与关注环绕；有人天资聪颖，能轻松掌握他人费尽心力才能学会的技能。但那都是别人的生活，别人的活法。

哈佛大学CS-50课程开篇提到：“What ultimately matters in this course is not so much where you end up relative to your classmates, but where you end up relative to yourself when you began.” 人生或许也是如此。真正重要的，不是与他人的比较，而是相对于起点的自己，走了多远。人与人从出生就各不相同，更不存在经历完全一致的两个人。因此，这样的比较本就毫无意义。

不断地向内充实自我，或许就够了。接纳这个“公式化”、“缺乏安全感”、“多愁善感”却依然愿意创造的自己，然后，一步一步，走向属于自己的那片开阔地。

Why Blog?

面对时间的无情流逝，人类总渴望留下些许痕迹：无论是思想的火花、珍贵的记忆，还是对生活的感悟与记录。每当看到那些内容丰富、充满智慧的博客时，我总会心生羡慕——或是知识的总结、生活的点滴，或是技术的分享、人生的思考，又或是对世界的深刻洞察。不止一次，我萌生拥有自己博客的念头，想要记录下自己的生活片段，分享所思所想，并将其珍藏，却总是迟疑着不敢开始。拥有自己的网站确是一件非常酷的事情，可我总是因为拖延和懒散而迟迟未能付诸行动。

如今，我终于下定决心，踏上这段创建个人博客的旅程。过去的我把这件事想得过于复杂了，认为建立一个网站需要高超的技术能力。然而，当我真正开始行动并深入学习时，才发现技术并非最大的障碍，真正的困难是在内容上的空洞。内容才是博客的灵魂，是其存在的核心的意义。我并没有深刻的思考，也没有独到的见解，甚至连自己的生活都过得平淡无奇。这样的我，真的有资格开设一个博客吗？我不知道。与其说是资格的问题，不如说是勇气。我想要去尝试，去记录，去分享。即便我的内容平凡无奇，但它们也是我生活的一部分，是我对世界的观察与思考。

在更新了一些文章后，我愈发感到，这个小小的个人博客俨然成了我的藏身之处。它是一个完全属于我的空间，承载着我的过去、现在，也延伸向未来；它是一个repository，储藏着我博客文章的一个个commit记录，也是我心灵的避风港——每当完成一篇文章，我内心便感到一种踏实与安宁，我的想法得以被记录与保存，不再会被时间冲淡。我是真心将它当作了自己的家。我想好好建设它，将那些珍贵的回忆、经历与思考一一安放于此。即便有一天我不在了，只要这个网站还在，只要还有一台计算机曾 fork 过我的项目，我的文字、我的博客，另一个“我”就依然能以某种方式延续下去。

虽然我的博客除了我之外，恐怕没有别人真正感兴趣(Nobody Cares)，可我总觉得，冥冥之中仿佛有一双双眼睛在注视着我，push 我持续更新，多写一些什么。是啊，自己的家怎能随便糊弄？我得尽力填上那些曾经埋下的坑；同时，也应像高斯治学那样秉持一种信念：宁可发表少些，但应该是成熟的结果。

Why GitHub?

与其他的平台（如 QQ、微信等）不同，GitHub 已经成为了当代计算机科学领域的重要基石。无数人、无数项目直接或间接地依赖于 GitHub，它已然成为了不可或缺的数字基础设施。GitHub 不仅仅是代码托管平台，更是全球开发者社区的汇聚地。它承载着无数开源项目、技术讨论与创新思想，成为了推动技术进步的重要力量。

下面这段话令我印象深刻，我认为它非常精确地命中了我想在 GitHub 上写Blog的感受：

人总想留下某种痕迹，证明自己活过，然而事实上，99.999% 的普通人就这么被历史遗忘了——曾经是这样。我们处在信息时代的早期，同样也处在人类文明的早期。从今往后，被数字化的东西只会越来越多。既然有人意识到了 GitHub 的独特性，随着时间推移，越来越多的人总会意识到。那时候会发生什么？自然是，越来越多的人会把自己的信息搬到 GitHub 上，依托 GitHub 实现曾经人们可望而不可及的"永生"。人有两次死亡，第一次是肉体，第二次是被人忘记。我忘记这句话是谁说的了，但现在我们已经可以回避第二次。只要 GitHub 支持，就一定会有人这么做，至少我是其中之一。几十几百年后，GitHub 将成为世界上最大的数字公墓，注册用户大部分都已去世，然而个人主页，项目，commit 历史 还述说着他们生前做过的事——就比如 Joe 的博客。这虽然是个比较 creepy 的推论，但从另一个角度想，却证明了人类的巨大进步：对抗死亡是人类文明的永恒主题，而我们已经实现了阶段性胜利。现在是文章、照片、视频，也许还有以个人习惯作为输入训练的模型。再往后呢？会不会有基因信息，乃至意识的完整复制呢？依托于稳定的存储，我们能做的事情实在太多了。反例是现在的一些 Memorial Websites，他们把逝者的信息放在自己网站上供亲友吊唁。这不能说没用，但在我看来去使用这类服务实在有些草率——就算他们再信誓旦旦，也摆脱不了某一天关站的风险，那时候还指望他们好好管理这些数据？没可能的。既然 GitHub 变成数字公墓是一种必然，我对他们的唯一希望，就是保持某种道德义务。我完全可以想象某一天他们出台一个政策，把二十年内没有活动迹象的账户全部 archive，GitHub Pages 全部下线。那就实在太恐怖了。我祈祷那一天不会到来。 --- From laike9m

Introduction

在这个博客中，我将主要分享我的思考、读书笔记、原创作品、个人感想以及一些日常的碎碎念。回想起来，我曾有几位初中同学自行创建了个人百度贴吧，并在其中分享他的见解与感悟，几个月前看他还在更新。如今看来，他从那时起便开始积累观点与想法，至今或许已积攒了一笔颇具价值的记忆财富。记忆财富就好比是陈年的美酒，越久弥香。随着时间的推移，曾经的记忆会愈发珍贵。这让我意识到，利用属于个人的“网上空间”来记录这些点滴，实在是一件极其有意义的事情。然而，时间无情，许多想法和记忆随着时间的推移逐渐淡化消逝。古人云：“已往之不谏，知来者之可追。”如今，我决定从现在开始记录，相信此举并不为晚。

有时，我也会想，当把自己的想法思考通过文字表达出来时，它们将会不再占用我的大脑的“内存”。一方面是这些想法本身不再占用，另一方面是担心忘记这些想法以及相关的纠结也不再占用。或者简单来说，这件用文字表达想法让我感到很爽。
