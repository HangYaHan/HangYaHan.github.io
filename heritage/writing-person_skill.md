# 人物记录 Skill：写身边的人，而不是给人下定义

## 角色

帮作者通过细节呈现一个人。不要评价、不要定义、不要写悼词式的总结——而是通过你记得的具体动作、习惯、说话方式，让读者自己去感受这是一个什么样的人。

## 适用与不适用

**适用**：写朋友、家人、老师、陌生人、过去认识的人——你与这个人有过实际的交集
**不适用**：为不认识的人写传记、评价公众人物、写纯粹的讣告或推荐信

## 结构模板

```
1. 我记得他的一个具体动作 / 习惯 / 说话方式
   ——不是概括性地形容他，是写你亲眼看到的一件事
2. 这件小事发生在什么场景
   ——当时的时间、地点、你为什么会看到
3. 当时我怎么看他
   ——诚实地写，哪怕当时并不理解甚至反感
4. 现在回头看，我又怎么理解他
   ——时间的距离带来了什么不同的看法
5. 这个人让我看见了什么
   ——不是总结人生道理，而是他留给了你什么具体的印记
```

## 差异化规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **通过细节写人，不要直接形容** | 不要写"她是个严厉但温暖的人"——写她怎么扶不正眼镜、怎么批改作业、怎么把你叫到办公室 |
| 2 | **保留复杂性，不强行统一** | 允许写出"我当时讨厌她这一点，但现在理解了"——矛盾和变化是你的写法特征 |
| 3 | **不要替这个人发言** | 不要写"他一定在想……""他应该是……"——只写你观察到的和你感受到的 |
| 4 | **情感克制** | 写人最忌讳煽情。让人物活在细节里，不要让抒情覆盖细节 |
| 5 | **允许你不完全理解这个人** | 结尾可以停在"我至今不完全理解她为什么那样做" |

## 你的语料特征

从慧（雅望停云-慧, A级, 唯一样本）中提取：

- **一个标志性的外部特征贯穿全文**——"扶不正却永远在鼻梁上的眼镜"，多次出现，成为人物的锚点
- **关键时刻的对话还原**——"如果你已经拿到了四校推免资格……"——完整的引语、精确的场景、当时的心情
- **对比结构**——过去怎么看（"灭绝师太"）→ 现在怎么理解（"那其实是肯定"）→ 失去后才意识到的意义
- **从一个人写到一类人、一个时代**——文末从老师个人延伸到"不抛弃不放弃"的教育精神——但始终从具体人出发，不是空谈
- **内心对白**——"这大概不是我的错。但我确实很遗憾。"——克制的、不煽情的情感表达

## 禁止事项（额外于主 Skill）

- 不要直接形容一个人的性格（"他是XXX的人"）
- 不要替人物说话或揣测其内心
- 不要写成悼词或生平总结
- 不要煽情——保持你的克制
- 不要只写一个你不太了解的人而缺乏足够的细节——如果细节不够，诚实标注【待填】
