# 摘抄

- 魔鬼从来都是在人们最乐观的时候发动攻击的。
- 离市场远一点，你才能真正看清楚市场的脉络走势。过多的资讯会干扰你对市场的判断，它们会像噪声一样让你听不清市场本身的音乐，并会让人迷失本性。
- 可惜一旦进入市场，我们就迷茫了。我们不仅不会远离市场，反而想方设法与市场距离近点、更近点。甚至，最好能够打入市场内部。大量号称专业的投资者不就是以“有内部消息”作为其权威卖点吗?
- 你想去哪儿？
- 很多人就像兰兰一样，一见我就问我该如何理财。这个问题其实很像向别人问路。如果你在街上碰到一个人，向你问路该怎么走，你要怎么回答呢?不告诉我目的地，我如何指路?在街上问路的人都知道自己想去哪儿，但向我求教理财的人大部分都没有想清楚自己想去哪儿。所以，你们要想让我教你们理财，首先要想清楚自己想去哪儿，也就是所谓的理财目标。
- 人生无非是首先要活在当下，然后还要有远大理想。理财的目标也就是这两个方面:首先是要安排好当前的生活，将家庭资产做合理的储蓄和投资，合理安排家庭的收人和支出等，为自己及家人建立个安心富足的生活方式;第二个层面的内容是为未来的人生做好安排，未雨绸缪，努力达成人生各阶段的各种目标和梦想，比如今年买辆进口车、过两年换个大点的房子，每年能够到国外旅行一次、送孩子留学等。当然，在理财这个问题上，所有人都会关心一个终极问题--财务自由。所谓财务自由，就是通过建立一个终生的现金流渠道，保障自己和家人过上无忧无虑的生活，不用再为金钱而工作，这就是所谓的财务自由的境界。
- 我说这么多，并不是说我认为现在社会财富的分配是公平的，也不是说社会的贫富差距是正常的，更不是说一线体力劳动者收入就应该低。我真正想表达的是:
  - 第一，财富的分配是生产各要素在市场上进行交换而形成的生产要素价格体系决定的，也就是说财富的分配是市场决定的不是说谁想多分就可以多分。
  - 第二，财富的运动有其内在的规律，我们要做的是学习这个规律，顺应这个规律，而不是质疑这个规律是否合理，只有这样你才能成为财富的赢家。
  - 第三，要想在财富上获得成功，对待财富一定要有一个正确的心态,对待财富成功者也要有一个正确的心态。这个正确的心态就是尊重财富，尊重财富创造者，也尊重财富的拥有者。
- 这是现在我们世界的真实情况，我们确实已经失去了对真理的敬畏、对真理的热情，甚至对真理的追求。我们每天追求的就是利益。决定我们行为的准则已经不再是对错。趋利避害成为了我们一切行为的准则。
- 凡是将自己财务的失败归结为没有一个好爸爸或运气不好、社会不公的，都是在为自己的失败寻找借口。更重要的是，一个一直在找借口的人，他的命运是无法改变的。
- 最后，我再一次问大家:你们的人生有目标吗?你们考虑过怎样度过自己的一生吗？财富的所有目标都是为人服务的。
