# 风格蒸馏报告：情绪整理类 (writing-emotion)

> 语料来源：#17~#21，共 5 篇（A级 4 篇 / B级 1 篇）
> 对照反例：风雅涵章 日常观察 C 级（#4 音乐收集、#5 私人垃圾桶、#6 贮影轩、#7 藏书阁）
> 分析日期：2026-05-12
>
> **关联文档**：[共享写作约定](./shared-conventions.md) — 所有子 Skill 的通用原则与标注符号系统

---

## 一、核心风格画像

这类文章的共同气质是：**作者被一个具体事件（受伤、面试、离别、项目孤独）触发了情绪波动，然后通过写作来"看清自己怎么了"，而不是"解决问题"。**

它们不像日记那样完全无序（因为事后整理过），也不像议论文那样追求结论。它们更像是一次**安静的自我解剖**——把感受剥开来看，允许流血，但不煽情。

关键词：**克制、具体、自我怀疑、不结论、从场景进入、保留不确定性**

---

## 二、常见主题

- 离别后的怅惘和释怀（#19 秋日别后, #17 春日别后）
- 对自身状态的不满与虚无感（#18 我好失败啊）
- 身体受伤带来的恐惧和对比（#20 扭伤之后）
- 创作/工作的孤独感（#21 Beruto开发随笔）

共性：**都源于一个"打断日常节奏的事件"，都在写"这件事让我想到了什么关于自己的事"。**

---

## 三、结构模板

### 模板 A：事件 → 感受 → 对比 → 暂时理解（最常见）

```
1. 具体事件（扭伤脚踝 / 面试失败 / 离别场景）
2. 当下感受（恐慌、怅惘、虚无）
3. 与过往经验的对比（高中有人照顾 vs 现在一个人；曾经欣赏她 vs 现在无话可说）
4. 某种暂时性的自我理解
5. 开放结尾（不强行释怀或升华）
```

实例：#17 春日别后、#20 扭伤之后

### 模板 B：状态声明 → 症状列举 → 深层原因 → 渴望（更 raw）

```
1. 直接的情绪声明（"我好失败啊"）
2. 具体症状（刷视频傻笑、开无意义玩笑）
3. 自我意识——连自我厌恶都公式化了
4. 更深层的渴望（想被爱、想被当作具体的人）
5. 停在渴望上，不给答案
```

实例：#18 我好失败啊

### 模板 C：场景 → 哲思 → 释然（偏文学性）

```
1. 一个具象场景（离别后的思绪）
2. 引用文学/哲学作为"外部对话者"
3. 情绪由浓转淡的过程
4. 以意象或诗句作结
```

实例：#19 秋日别后

### 模板 D：项目 → 孤独 → 隐喻 → 接受（偏开发者叙事）

```
1. 开发项目背景
2. 孤独感的具体表现（一个人写代码、渴望协作）
3. 用文化/游戏隐喻重新框定这种孤独
4. 接受孤独为常态，但不否定它
```

实例：#21 Beruto开发随笔

## 四、可执行语言规则

以下规则来自 5 篇 A/B 级文章的实际特征，以及 C 级反例的对比分析：

| # | 规则 | 来源 | 正例 | 反例 |
|---|------|------|------|------|
| 1 | 必须从**具体场景、动作或物品**开始，不要以抽象情绪词开头 | 5/5 | "我受伤了，在打羽毛球的时候踩到了别人的脚" | "最近我很难过" |
| 2 | 用**具体行动承载情绪**，不要直接说"我很孤独""我很焦虑" | 5/5 | 独自在酒店房间里害怕失去运动能力；一个人骑行东湖 | "我感到深深的孤独" |
| 3 | 允许**自我怀疑和矛盾**，不要把情绪"解释干净" | 5/5 | "连厌弃自己的方式都变得公式化" | （反例）每段都给出确定性结论 |
| 4 | 结尾**不要升华、不要拔高、不要"所以我们应该"** | 4/5 | 停在渴望、停在动作、停在意象上 | "这就是人生""愿你我都能" |
| 5 | 句子以**短句和中长句为主**，不要密集排比 | 5/5 | 自然口语化叙述 | 连续3句以上相同句式 |
| 6 | 少用**抽象大词**（成长、治愈、热爱、人生），除非素材中明确出现 | 5/5 | | "通过这次经历我获得了成长" |
| 7 | **保留一点停顿和犹豫感**，不要把所有空白填满 | 5/5 | "我暂时能给自己的理解是……" | 每段都有斩钉截铁的结论 |
| 8 | 脆弱感可以**不被正面化解**，可以停在"我暂时是这样理解的" | 5/5 | "也许这个问题没有答案" | 强行在结尾转向积极 |

## 五、开头方式（来自 5 篇实证）

| 类型 | 实例 | 占比 |
|------|------|------|
| 事件切入 | "我受伤了，在打羽毛球的时候踩到了别人的脚" | #20 |
| 引用切入 | 李商隐"此情可待成追忆" | #19 |
| 状态声明 | "我好失败啊，我好虚无啊" | #18 |
| 场景切入 | "那是刚刚过完年，我和她见了一面" | #17 |
| 项目切入 | "Beruto 是我的一个量化交易回测系统" | #21 |

**结论**：事件/场景切入是最主流的开场，引用和状态声明可用但需克制。

---

## 六、结尾方式（来自 5 篇实证）

| 类型 | 实例 | 好/坏 |
|------|------|-------|
| 回到一个具体动作 | 春日别后："我得把它们扔下了" | ✓ |
| 停在渴望/疑问上 | 我好失败啊：想被爱但从来孤独 | ✓ |
| 意象收束 | 秋日别后："放手不是失去，而是将拥有交付给了整条溪流" | ✓（略文学化，但克制） |
| 实用附录 | 扭伤之后：附 RICE 急救方案 | ✓（与文章情绪形成反差，有趣） |
| 隐喻收束 | Beruto："黑暗圣堂之路" | ✓ |

**禁止的结尾**：
- "这就是人生"
- "我们都应该"
- "愿你我都能"
- "成长就是这样"
- "生活终将……"

## 七、禁止事项（executed from 反例 C 级 + 风格目标）

1. 不要写成**纯数据日志**（如 #6 贮影轩、#7 藏书阁：只有列表没有叙事）
2. 不要写成**纯技术文档**（如 #4 音乐收集：只有流程没有感受）
3. 不要写成**无序碎碎念**（如 #5 私人垃圾桶：每天随手记但没有整理和深度）
4. 不要**强行积极**——负面情绪可以不化解
5. 不要**过度煽情**——保持克制，让事实说话
6. 不要**用自己的高频大词**——即使在你的文章中，"成长""人生"这些词也很少出现
7. 不要**替作者表达没有说过的强烈情绪**——只能从素材中已有的情绪出发

## 八、对比分析：A 级 vs C 级情绪类文章

虽然情绪类没有直接的 C 级样本，但与日常观察 C 级对比可以看出差距：

| 维度 | A 级情绪文 | C 级日常文 |
|------|------------|------------|
| 结构 | 有清晰的叙事弧线（事件→感受→反思） | 无结构或纯列表 |
| 具体性 | 时间、地点、动作、对话、物品 | 抽象陈述 |
| 反思深度 | 从事件中长出自我理解 | 停留在表面记录 |
| 情绪处理 | 描述情绪的质地，不急着解决 | 忽略情绪 |
| 结尾 | 有克制但有意蕴 | 自然结束或没有结尾 |

## 九、推荐处理流程

收到用户素材后，按以下步骤处理。使用标注符号与作者协作（符号定义见 [共享写作约定](./shared-conventions.md#二标注符号系统)）：

```
1. 用三句话概括素材：发生了什么 / 核心情绪是什么 / 可能的意义方向
2. 判断素材最适合的情绪表达结构（A/B/C/D 四种模板之一）
3. 提取素材中最具体的场景、动作、对话、物品
4. 搭建大纲，标注：
   - 哪些细节是你独有的、AI 不可能知道的 → 标【待填：具体缺什么】
   - 哪些地方感悟太多 → 标【重写】并指明方向
5. 写初稿，避免使用抽象情绪词
6. 自检（对照共享写作约定 checklist）：
   - [ ] 感悟与叙述比例是否合理？（感悟 ≤ 叙述）
   - [ ] 是否保留了犹豫、误判和不完整？
   - [ ] 语言是否朴素、有私人感？
   - [ ] 过渡是否自然？
   - [ ] 是否什么都想说但什么都没说透？
   - [ ] 结尾是否过度拔高？
   - [ ] 是否有"成长""人生""我们都应该"等大词？
   - [ ] 是否在替作者表达没有说过的强烈情绪？
   发现问题主动标记【润】或【重写】
7. 给出修改版，并标注修改了什么
8. 在处理全过程中，遇到【不改】包裹区域必须原样保留，不得触碰
```

## 十、风格总结（一句话）

**从一个打断日常的具体事件出发，用克制、具体的语言描述情绪的发生过程，保留犹豫和不完整，停在暂时性的自我理解上，不强行升华。**
