# 爷爷走后的那个早晨，我听懂了鞭炮声

棺材旁边的七星灯火苗在夜里    ，遗像前的三柱香飘散出青烟。

# 喧嚣里的困惑

说实话，刚回到老家奔丧时，我是带着一种“现代人的傲慢”的。

以前的我不理解。失去亲人明明是一件悲伤彻骨的事，为什么灵堂外面的酒桌上，亲戚们能推杯换盏，甚至谈笑风生？为什么前一秒还在遗体前哭得撕心裂肺的人，下一秒就能转身去安排流水席的菜色？

看着那些繁琐到近乎折磨人的仪式——没完没了的跪拜、震耳欲聋的鼓乐、还有那些讲究到极致的披麻戴孝，我心里只冒出几个词：落后、愚昧、死要面子。
在这个讲究效率和科学的时代，这些农村的旧习俗，

像是一块格格不入的补丁。

直到那个凌晨，两件事彻底击碎了我的傲慢。

2. 凌晨五点的磕头声

守灵的第三个晚上，大概是凌晨 5:00。天还是墨黑的，露水很重。灵堂外突然走进来一个人，背着一个旧旅行包，风尘仆仆。那是我的一个远房表叔。

后来我才知道，他在广州做环卫工。听到爷爷去世的消息，他买了当晚的绿皮火车站票，熬了一整夜，下了火车又转班车，赶在天亮前到了村口。

他没有寒暄，没有客套，甚至没顾得上喝口水。
他只是默默地把包放在门边，径直走到灵堂前。点香，下跪，“咚、咚、咚”三个响头。磕得实实在在，额头撞击地面的声音，在清晨寂静的灵堂里显得格外清晰。

做完这一切，他才瘫坐在旁边的塑料椅上，喘了口粗气。
看着他那双因为赶路而满是疲惫的眼睛，我突然感到一阵哽咽。

那一刻我明白了，这不仅是仪式，这是他能给出的最笨拙、也最厚重的敬意。在这个讲究“原子化”生存的社会里，还有人愿意跨越千里，只为在这个灵前，磕上几个头。这哪里是面子，这是刻在中国人骨子里的情义。

3. 全村的鞭炮

出殡那天，队伍走得很慢。
按照习俗，灵柩要绕村一周。我原本以为这只是个过场，但当我捧着遗像走过村道时，眼泪真的止不住地往下流。

每经过一户人家，无论那家人在干什么，都会停下手里的活，站在门口，点燃一挂鞭炮。
噼里啪啦的硝烟味弥漫在整个村子上空。那些老人看着灵车，眼神里没有恐惧，只有一种无声的送别。

爷爷是个空巢老人，大半辈子都守在这片土地上。对于我和那些早已搬进城市的子孙来说，这里只是故乡；但对于村里人来说，爷爷是他们朝夕相处的邻居、伙伴、亲人。
“远亲不如近邻”，这句老话在这一刻具象化了。
这满村的鞭炮声，是这片土地给予它子民的最高礼遇。

4. 最后的告别

后来，当一切归于平静，我独自坐在老屋的门槛上，重新审视这一切。

我不再觉得那些仪式是“迷信”了。
我想，或许正是因为死亡太冷、太痛、太虚无，活着的人才需要搞出这么大的动静，需要这么繁琐的流程。

我们需要用身体的极度疲惫，来宣泄内心的悲痛；
我们需要用流水席的喧闹，来对抗从此少了一人的死寂；
我们需要这场盛大的聚会，让平时散落在天南海北的亲人，有一次名正言顺的团聚。

就像费孝通先生笔下的乡土中国，葬礼不仅仅是送别死者，更是为了抚慰生者。
对于爷爷那一辈人来说，他们没有受过现代科学教育，他们相信灵魂不灭，相信来世。这是他们的局限，也是他们的信仰。作为晚辈，如果不去理解他们的成长环境，就站在道德高地上指指点点，那才是真正的“狭隘”。

# 写在最后

爷爷的葬礼结束了。
看着老屋斑驳的墙壁，我意识到，这可能是我最后一次见到亲戚们这么“齐”了。
随着老人的离去，老屋终将空置，我们这群人也将回到各自的城市，继续在钢筋水泥中忙碌。

那些繁琐的习俗，也许终有一天会消失。但在那个火光摇曳的夜晚，在那个表叔磕头的瞬间，我确信自己触摸到了某种温热的东西。
那不是迷信，那是中国人面对死亡时，特有的深情与体面。

妹妹又往火盆里添了一把纸，火光映着她的脸。
“爷爷会收到吗？”
这次我摸了摸她的头，轻声说：“会的，一定会的。”

妹妹蹲在旁边，红扑扑的小脸被火光照亮，她突然扭头问我：“哥，你知道为什么要烧纸吗？”
我愣了一下，还没来得及用唯物主义那一套解释，她就自己接了话：“爷爷到那边要用的。”

那一刻，我把到了嘴边的“迷信”两个字咽了回去。
