# 事件复盘 Skill：把经历写成有层次的文章

## 角色

将一段有明确起止的经历写成一篇清晰、有层次、有自我觉察的复盘文章。核心不是记录发生了什么，而是呈现**这件事如何改变了我**。

## 适用与不适用

**适用**：有明确起止的事件（面试、旅行、年度/季度复盘、项目开发、意外事件、一次重要对话或决定）
**不适用**：没有时间边界的日常情绪、纯观点讨论、以一部作品为核心的内容

## 结构模板

### A：背景 → 经过 → 转折 → 反思 → 余波（最标准）

```
1. 背景：这件事发生在什么情况下，我当时的处境、预期和心态
2. 经过：发生了什么——抓关键场景和节点，不写流水账
3. 转折：哪个瞬间让我意识到不一样——可以是别人的一句话、一个结果、一个停顿
4. 反思：我从中看到了自己什么——不是总结教训，是更准确的理解
5. 余波：这件事之后我有什么具体变化——行为、心态、决定的改变
```

### B：结果 → 倒叙 → 分析 → 教训（适合失败/复盘）

```
1. 结果先行——先说结果是什么（面试没过、硬盘坏了、投资亏损）
2. 倒叙经过——关键的决策点
3. 分析——当时为什么做了那个选择
4. 教训——但不要写成"应该/不应该"的说教，而是"现在回头看，我理解了什么"
5. 前行——接下来具体要做什么改变
```

## 差异化规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **抓转折点，不写流水账** | 一件事有无数细节，但只有 1-2 个瞬间真正改变了你 |
| 2 | 反思从**经历中长出来** | 不要在文末突然插入一段"总结与展望"，反思应该贯穿叙述 |
| 3 | 保留**当时的误判和局限** | 不要用事后诸葛亮的视角删除当时的错误判断——那才是文章最有价值的部分 |
| 4 | 余波要**写具体** | "这件事让我变得XX"太虚 → 写你接下来具体做了什么不同的决定 |
| 5 | 不要写成**工作总结或实验报告** | 删除"项目概述""技术栈""方法"等标题；把技术细节转化成个人视角 |

## 你的语料特征

从你的 A 级复盘文（离开了AI、2025年度总结、记一次葬礼、2024投资复盘）中提炼：

- **开场有力**——"聪明的努力，最后只值一句 prompt""带着现代人的傲慢"——直接进入，不铺垫
- **解剖而非辩解**——写自己的失误时细致、诚实、不找借口
- **具体改变有跟踪**——不只是"我学到了"，而是"接下来我做了 X 和 Y"
- **年终总结有模板化倾向**——你把年度文章分了板块（科研、社交、健康），这是你的偏好格式，可以保留

## 禁止事项（额外于主 Skill）

- 不要写成流水账（今天做了A、然后做了B、最后做了C）
- 不要写成工作日报或项目周报
- 不要在反思部分突然变成说教模式
- 不要删除当时的错误判断（那是好文章的核心）
