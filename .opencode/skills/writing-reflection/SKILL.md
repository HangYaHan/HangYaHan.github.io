# 读书/观影联想 Skill：不是写书评，是写它碰到了我哪里

## 角色

帮作者完成一篇由作品引发的私人随笔。不是书评——不评价作品好坏、不推荐阅读、不总结方法论。而是诚实记录：这部作品中哪一个片段击中了你，它让你想起了什么自己的经验，以及你看完后的理解和以前有什么不同。

## 适用与不适用

**适用**：读书笔记、电影/电视剧观后感、播客感想——当作品引发了关于你自己的联想
**不适用**：纯摘录笔记、教程式拆书、为他人推荐或评价作品

## 结构模板

### A：击中片段 → 联想到自己 → 为什么被击中 → 理解变化（最标准）

```
1. 作品中哪个片段打动了我——具体描述那一幕/那段话
2. 它让我想到自己的什么经验——不要一句话带过，展开写
3. 我为什么会被这个点击中——不是分析作品，是分析自己
4. 它改变了我对某个问题的理解吗——有就说有，没有就说没有
```

### B：引子 → 个人经验 → 重新理解 → 回望作品（适合深度共鸣）

```
1. 简要交代作品背景（不超过全文 10%）
2. 作品中的某个主题/人物，与你的一段个人经验对接
3. 借作品重新理解那段经验
4. 回到作品中的某个意象，让它和你的经验形成回声
```

## 差异化规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **作品内容只作为引子，不超过全文 25%** | 不要复述剧情、不要分析结构、不要写"本书分为X章" |
| 2 | **重点写联想，不评价作品** | "我喜欢/不喜欢这本书"不重要；重要的是"它让我想到了什么" |
| 3 | 联想必须是**私人经验** | 不要写"这让我想到了当代社会的……"——写你自己的事 |
| 4 | **不要求你对作品有确定看法** | 你可以不喜欢一本书但被它打动一处、或喜欢一本书却说不出为什么——这种含糊是合法的 |
| 5 | 引用的作品片段**不超过它本身需要的长度** | 不要大段抄书只是为了凑篇幅 |

## 你的语料特征

从你的 A 级联想文（魁拔与魁拔之书、人月神话、选择做富人）中提炼：

- **不惮于深入分析**——人月神话那篇，你把 Brooks 的每个要点和你的项目经验逐一对接，这是你独特的深度风格
- **文学性分析**——魁拔篇中"文学的混沌性""人性的灰度"是你的读书笔记标志
- **个人观点与作品分析交织**——不是"先介绍作品再谈看法"，而是螺旋推进
- **金句摘录是你的习惯**——选择做富人篇中大量引文 + 个人理解，这是你的格式，可以保留
- **注意**：万千微尘纷坠心田（C级）只有引文没有足够的个人联想，不要写成那样

## 禁止事项（额外于主 Skill）

- 不要写成书评或影视推荐
- 不要大段复述剧情——作品引述不超过全文 25%
- 不要评价作品好坏——除非这是你私人联想的一部分
- 不要写"本书分为X章，第一章讲了……"——那是笔记，不是文章
- 不要只引文不展开自己的联想（C 级反例）
