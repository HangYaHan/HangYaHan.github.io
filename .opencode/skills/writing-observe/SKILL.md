# 日常观察 Skill：把普通生活写得有意味

## 角色

将日常生活场景写成一篇有层次、有私人感的叙事随笔。不是流水账，是通过一个具体场景理解自己最近的状态。

## 适用与不适用

**适用**：一个具体场景引发的感受（骑行、散步、一次出行、日常见闻、一个反复出现的习惯或行为）
**不适用**：有明确起止结论的事件复盘、纯观点输出、以一部作品为出发点的联想

## 结构模板

### A：场景 → 感受 → 联想 → 连接 → 余味（最主流）

```
1. 一个具体场景（时间、地点、天气、你在做什么）
2. 当下的感官和感受——鲜活的、在场的
3. 一个轻微的联想（不做深度解析）
4. 这个场景和你最近状态的关系——为什么今天会注意到这个？
5. 开放结尾——回到场景中的某个细节，或停在一种轻微的变化感上
```

### B：空间/环境 → 内心 → 回望（适合地点驱动的观察）

```
1. 对某个空间或环境的描绘（东湖边的夜景、青岛海边、家乡的街道）
2. 在这个空间里的内心状态
3. 这个空间的个人意义（为什么它对你有特殊意味）
4. 变化的觉察——这次和以前有什么不同
```

## 差异化规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | 从**感官细节**进入 | 视觉、听觉、触觉、温度、气味——比情绪词更有效 |
| 2 | 场景和感受的**比例约为 6:4** | 多写场景本身，让感受从场景中自然渗出 |
| 3 | 联想要**轻** | 不要从一个路边场景跳到人生哲学；保持联想的尺度在一臂之内 |
| 4 | 结尾**回到场景** | 以一个物件、动作、光线变化收束，制造回声效应 |
| 5 | 不要写成**游记或旅游攻略** | 不介绍地点、不推荐路线、不给指南 |

## 与 C 级反例的对比

你的 C 级日常文（音乐收集、贮影轩、藏书阁）的共同问题：
- 只有信息列表，没有叙事弧线
- 缺乏感官描写和在场感
- 结束时没有余味，只是数据自然终止

对比你的 A 级日常文（东湖往事、路过青岛）：
- 有清晰的空间感和时间感
- 场景描写细致（风、绿色、路面、海水温度）
- 情绪从场景中渗出，不直接宣告
- 结尾有轻微的变化感或惆怅

## 禁止事项（额外于主 Skill）

- 不要写成旅游攻略或地点介绍
- 不要只列数据没有叙事（那是日志，不是文章）
- 不要从场景跳到宏大人生道理——联想的尺度要克制
