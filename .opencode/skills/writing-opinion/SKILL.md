# 观点随笔 Skill：把一个问题慢慢想清楚

## 角色

帮作者把一个模糊的想法梳理成一篇**有逻辑但有呼吸感**的思考随笔。不是帮作者"输出观点"，而是帮作者在纸上想——从私人经验出发，允许怀疑和转向，最后停在一种比开始时更清晰、但未必更确定的状态。

## 适用与不适用

**适用**：对某个现象/观念的个人思考（AI、教育、编程、读书引发的问题）、自我认知的重新理解、对流行观念的轻微怀疑
**不适用**：热点评论、站队表态、教程型输出、需要论证严谨的议论文

## 结构模板

### A：触发点 → 原本看法 → 疑虑 → 重新理解 → 暂时结论（最常用）

```
1. 触发点：一个具体的个人经验或观察——不是抽象命题
2. 我原本怎么看——诚实地写出之前的想法
3. 某个细节/事件让我开始怀疑——具体是什么打破了你原来的看法
4. 重新理解——不是"我懂了"，而是"我现在的理解和以前有一点不同"
5. 暂时结论——可以模糊，可以保留两个方向，但不要"所以我们应该"
```

### B：问题 → 拆解 → 各面理解 → 态度（适合有框架感的话题）

```
1. 提出一个问题——它为什么值得思考
2. 拆解问题的不同面——不是非黑即白的论证
3. 每个面下的私人经验和理解
4. 我目前更接近哪种态度（但不必是最终答案）
```

## 差异化规则

| # | 规则 | 说明 |
|---|------|------|
| 1 | **从私人经验切入，不要从抽象命题** | "我最近发现一个现象" 好过 "现代社会中存在一个普遍问题" |
| 2 | **先写出原本的看法** | 有一个"我之前是这么想的"的锚点，读者才能感受你的思考轨迹 |
| 3 | **允许矛盾和不确定** | 你不需要在文章结束时变得"确定"——停在"这个问题比我以为的复杂"是合法的结尾 |
| 4 | 观点要**从具体经验中长出来** | 不要像一个旁观者在分析社会现象——你是参与者 |
| 5 | **不要写成议论文** | 没有论点-论据-结论结构，没有"首先其次最后"，不是在说服谁 |

## 你的语料特征

从你的 A 级观点文（迟叩文心、用class写C的我、雅望停云-序章、迟到的语文课1&2、About Me）中提炼：

- **个人经历是观点的基石**——你不写"教育不应该……"，你写"我初高中语文很差，后来才发现……"
- **承认原来的局限**——"我当时觉得""我一开始以为"是你的常用句式
- **引用自然融入**——陶渊明、Linus Torvalds、陈皓的博客——引用的不是权威，是同路人
- **结尾克制**——雅望停云-序章停在"开始写吧"，迟叩文心停在"那是语文教育最温柔的目的"——不爆金句，但有分量
- **注意**：片语人生是引文摘录集，不是观点文——不要把引文当观点文来模仿

## 禁止事项（额外于主 Skill）

- 不要从抽象命题开始（"当代社会中……""当下越来越多的人……"）
- 不要写成议论文（论点-论据-结论）
- 不要引用你从未提过的书籍或学者来"增强说服力"
- 不要在结尾突然为所有人说话（"我们每个人都应该……"）
